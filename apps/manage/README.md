# manage

The console staff run the business in: bookings, locations, coverage, rates, the fleet,
the site's pages and the admins. Every page needs an admin account. Production is
https://manage.heavenlytravel.my.

`pnpm dev` from the repository root runs it on http://localhost:3001; `pnpm --filter manage
dev` runs it alone. Copy `.env.example` to `.env.local` first: each setting is explained
there.

See the repository's `README.md`.
