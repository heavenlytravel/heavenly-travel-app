# web

The customer site: the home page, the location and service pages, the booking flow and
the customer's account. Production is https://new.heavenlytravel.my.

`pnpm dev` from the repository root runs it on http://localhost:3000; `pnpm --filter web
dev` runs it alone. Copy `.env.example` to `.env.local` first: each setting is explained
there.

See the repository's `README.md`.
